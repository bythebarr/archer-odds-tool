# Team logos

Drop a square-ish logo file for each team here, named by its abbreviation as
stored in this app's database (confirmed against the `Team` table below).
`.svg` is preferred; `.png` also works. Until a file exists, that team shows
its abbreviation as a colored badge instead — nothing breaks either way.
